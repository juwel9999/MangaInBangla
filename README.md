# MangaInBangla

A personal manga reader and uploader web application for Bangla content.

- **Live Reader:** [https://juwel9999.github.io/MangaInBangla/](https://juwel9999.github.io/MangaInBangla/)
- **Upload Pages:** [https://juwel9999.github.io/MangaInBangla/upload.html](https://juwel9999.github.io/MangaInBangla/upload.html) (Requires GitHub Token)

## Setup

This project is hosted on GitHub Pages. The reader pulls chapter data from `library.json` and images from the `manga/` directory. Use the Upload page to add new chapters and pages.
